### Контекст и цель
На host 16.0.62.12 выявились ошибки штатного механизма команд; в dev-линию 0.8.0 вошли незапланированные опции. Фактически принятое решение: сфокусировать плагин на псевдокомандах, запускать alias через QuickInput popup или pseudo_command без динамической регистрации alias-имён в командном слое Robur, сохранить signature-safe dispatch и вынести заплатку кнопок/меню и полярные привязки в будущие плагины. Встроенный alias кф удаляется; команда pseudo_annotation_background_scale остаётся и назначается пользователем через редактор псевдокоманд.

### Состав текущей версии (после ревизии)
- Псевдокоманды: alias из aliases.json → штатная команда через QuickInput popup или pseudo_command; служебные команды имеют [cmd], alias-имена динамически не регистрируются; signature-safe dispatch защищённых целей сохраняется. После «Сохранить»/«Перечитать» alias доступен в QuickInput без перезапуска Robur.
- Редактор псевдокоманд (WinForms): таблица, импорт/экспорт, Отменить правки, О плагине, Сохранить; QuickInput и Space-as-Enter.
- Команда pseudo_annotation_background_scale (коэффициент маски мультивыноски): [cmd], Harmony-патчи Recreate/Layout, ввод коэффициента в настройках, action id_pseudo_annotation_background_scale в .plugin. ВСТРОЕННЫЙ ALIAS кф УДАЛЯЕТСЯ; доступ — через пользовательский alias (O1).
- Диагностика: pseudo_show_log, лог выключен по умолчанию, версия в About.
- ИСКЛЮЧЕНО ревизией: полярные привязки; заплатка штатных кнопок/пунктов меню и аварийные маршруты (нс, protected routes). Их перенос в отдельные плагины — вне этого цикла.

Пояснение диспетчеризации (закреплено 23, 2026-09-20): сохраняется фактическое поведение dev.8 — Execute + signature-safe маршрут для защищённых целей (RequiresPackedHandler → snapshot TryExecute) с тихой отменой (IsCancellation); InvokeAction-first маршрут v0.7.0 в dev-линии отсутствует и не восстанавливается («с учетом реализованного обхода штатного механизма вызова» — решение пользователя).
